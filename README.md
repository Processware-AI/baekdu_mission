인천상공회의소 산악회 백두산 3박4일(2026.09.10~13) 참가자용 안내 + 사진·영상 수집 웹앱.
**스마트폰 브라우저 전용**으로 만들어졌고, 데이터는 전부 **이 PC 안의 SQLite**에 저장됩니다.

## 1. 실행하기

**Node.js 20 이상**이 필요합니다 — https://nodejs.org 에서 LTS 버전을 설치하세요.

### 0) 소스 내려받기

```bash
git clone https://github.com/Processware-AI/baekdu_mission.git
cd baekdu_mission
```

> 비공개 저장소라 GitHub 로그인이 필요합니다.
> `git`이 없다면 GitHub 페이지에서 **Code → Download ZIP** 으로 받아 압축을 풀어도 됩니다.

내려받은 뒤 아래 OS에 맞는 방법으로 실행하세요.

### 🪟 Windows
`시작하기.bat` 파일을 **더블클릭**하세요.
검은 창이 뜨고 잠시 후 **브라우저가 자동으로 열립니다.**
그 창을 닫으면 앱이 종료되니, 쓰는 동안은 최소화만 해두세요.

### 🍎 macOS (맥 미니 등)
`시작하기.command` 파일을 **더블클릭**하세요. 터미널 창이 열리며 실행됩니다.

**처음 한 번만** 아래 두 가지가 필요합니다.

1. **실행 권한 주기** — 터미널을 열고 (Launchpad → 기타 → 터미널):
   ```bash
   cd <이 폴더 경로>      # 예: cd ~/Desktop/BaekDu
   chmod +x 시작하기.command
   ```
   폴더 경로를 모르겠으면 `cd ` 까지 친 뒤 폴더를 터미널 창으로 끌어다 놓으면 됩니다.

2. **보안 경고 넘기기** — 처음 더블클릭하면 macOS가 막을 수 있습니다.
   파일을 **우클릭(또는 Control+클릭) → 열기 → 열기** 를 누르면 이후로는 그냥 더블클릭으로 됩니다.

> **Windows에서 파일을 복사해 오셨다면** `node_modules` 폴더는 윈도우용이라 맥에서 동작하지 않습니다.
> 스크립트가 이를 자동으로 감지해서 지우고 다시 설치하니, 첫 실행 때 1~2분 기다리시면 됩니다.
> (직접 하시려면 `rm -rf node_modules && npm install`)

**맥이 잠들면 참가자가 접속할 수 없습니다.** 스크립트가 `caffeinate`로 서버가 도는 동안
잠자기를 막지만, **시스템 설정 → 디스플레이 → 고급 → "디스플레이가 꺼져 있을 때 자동으로 잠자기 방지"** 도
함께 켜두시길 권합니다.

### 터미널에서 직접 실행 (Windows / macOS 공통)
```bash
npm install     # 최초 1회
npm start
```

실행하면 접속 주소가 표시됩니다.

```
  이 PC        : http://localhost:8080
  같은 와이파이 : http://192.168.100.9:8080
```

### 처음 한 번은 설정 파일을
`.env.example` 을 복사해 `.env` 로 저장하고 **`SESSION_SECRET`** 과
**`ADMIN_PASSWORD`** 를 바꿔주세요. 안 바꿔도 동작은 하지만 보안상 권장합니다.

## 4. 사진 미션 (게임 규칙)

방문지마다 네 가지 사진 미션 + 영상을 올릴 수 있습니다.

| 미션 | 기본 점수 | 설명 |
|---|---|---|
| 🤳 독사진 | 10 | 나 혼자 (셀카 OK) |
| 👬 2인 사진 | 25 | 나 포함 정확히 2명 |
| 👨‍👩‍👦 3인 사진 | 45 | 나 포함 정확히 3명 |
| 👨‍👩‍👧‍👦 4인 이상 | 70 | 나 포함 4명 이상 |
| 🎥 영상 | 40 | 10~60초가 편집하기 가장 좋음 |
| 📸 단체사진 / 🎬 브이로그 | — | **운영진 전용** (점수 경쟁 제외) |

> ### ⚠️ 미션 한 칸에는 **한 장만** 남습니다
>
> 같은 방문지·같은 미션에 다시 올리면 **이전 것을 교체**합니다. 쌓이지 않습니다.
> 본인이 가장 잘 나왔다고 생각하는 사진(영상) 하나만 남기시면 됩니다.
>
> - 참가자 1명이 남길 수 있는 자료 = 방문지 21곳 × 미션 5칸 = **최대 105개**
> - 교체해도 **점수는 그대로** 유지됩니다 (선착순·정복 보너스도 회수하지 않음)
> - 교체된 이전 파일은 디스크에서도 즉시 삭제됩니다
> - **운영진의 단체사진·브이로그는 예외** — 여러 장 올릴 수 있습니다
>
> 여행 후 자료를 고르는 부담을 줄이기 위한 규칙입니다.

**보너스**

- 함께 찍힌 사람 **태그 1명당 +5** / 태그된 사람도 **출연 +3**
- ⭐ **핵심 스팟은 모든 점수 ×2** — 서파 1,442계단·천지·금강대협곡, 북파 천지·장백폭포, 윤동주 생가, 두만강
- 방문지 **선착순 1·2·3등 +30 / +20 / +10**
- 한 방문지에서 사진 4미션 완주 → **정복 +100**
- 하루의 모든 방문지 → **일차 완주 +50** · 전 일정 → **+200**
- 배지 9종 (첫걸음, 셀카왕, 인맥왕, 정복자, 감독, 번개, 개근상, 백두산 정복왕, 올클리어)

> 태그는 점수용 장치이면서, **여행 후 인물별로 사진을 자동 분류하는 핵심 데이터**입니다.

## 5. 사진이 저장되는 방식 ⭐

업로드 즉시 **방문지 / 미션별 한글 폴더**로 정리되어 저장됩니다.
따로 분류 작업이 필요 없습니다.

```
data/uploads/
  2일차_02_백두산 천지 (서파) · 경계비/
      01_독사진/     박화서_20260911-110233_a1b2.jpg
      02_2인/        손신기_20260911-110510_c3d4.jpg
      03_3인/
      04_4인이상/
      05_영상/
      90_단체사진/    ← 운영진
      91_브이로그/    ← 운영진
  3일차_02_장백폭포/
      ...
```

- 파일명 = `업로더이름_촬영시각_난수.확장자` → 사람별 정렬도 바로 됩니다.
- 원본 파일은 그대로 보관되고, 갤러리에는 가벼운 썸네일만 씁니다.

### 여행 후 내보내기 (운영진 화면 → 📦 내보내기)

- **ZIP 다운로드** — 위 폴더 구조 그대로. 전체 / 일차별 / 방문지별 / 미션별 선택 가능
- **`_manifest.csv`** — 파일경로, 일차, 방문지, 미션, 업로더, **함께찍은사람**, 캡션, 용량, 촬영시각

쇼츠 편집할 때:
`05_영상`·`91_브이로그`에서 영상을 고르고, `04_4인이상`·`90_단체사진`을 하이라이트로 쓰고,
CSV의 **함께찍은사람** 열로 인물별 편집본을 뽑으면 됩니다.

## 6. 현지(중국)에서 쓸 때 ⚠️ 꼭 읽어주세요

이 앱은 **이 PC에서 도는 로컬 서버**입니다. 백두산 현지에서 접속하려면 준비가 필요합니다.

**① 네트워크**

- **한국 통신사 로밍 데이터**로 접속하면 잘 됩니다. (트래픽이 한국을 거치므로 중국 인터넷 통제의 영향을 덜 받습니다.)
- **중국 호텔 와이파이**는 느리거나 막힐 수 있습니다. 이때는 그냥 사진을 고르고 **올리기만 눌러두세요** —
  아래 대기열이 알아서 처리합니다.

**② 업로드 대기열 (자동)**

연결이 끊기면 사진이 휴대폰 안(IndexedDB)에 저장되고, 화면 아래에 `대기 중 N개` 표시가 뜹니다.
신호가 잡히거나 앱을 다시 열면 **자동으로 업로드**됩니다. 같은 사진이 두 번 올라가지 않습니다.
→ **현장에서는 마음껏 찍고 올려두고, 호텔이나 귀국 후에 정리되게 두면 됩니다.**

**③ 화질 설정** (내 정보 → 업로드 설정)

| 설정 | 크기 | 언제 |
|---|---|---|
| 원본 그대로 | 원본 | 와이파이가 빠를 때 |
| **고화질 (기본값)** | 최대 2560px | 대부분의 상황. 쇼츠(1080×1920) 편집에 충분 |
| 데이터 절약 | 최대 1600px | 신호가 약할 때 |

영상은 항상 원본 그대로 올라갑니다.

**④ 외부에서 접속하게 하려면**

같은 와이파이가 아닌 곳에서 접속하려면 셋 중 하나가 필요합니다.

1. **공유기 포트포워딩** — 외부 8080번 → 이 PC 8080번. 가장 간단하지만 집 IP가 노출됩니다.
2. **터널 서비스** (권장) — `cloudflared tunnel --url http://localhost:8080` 한 줄이면
   `https://xxx.trycloudflare.com` 주소가 생깁니다. HTTPS라 카메라 기능도 안정적입니다.
3. **클라우드 서버에 올리기** — 가장 안정적. 이 경우 `.env`에 `COOKIE_SECURE=1`을 넣으세요.

> 📱 **HTTPS를 권장합니다.** iOS Safari는 HTTP에서 카메라 촬영이 제한될 수 있습니다.
> 터널(2번)을 쓰면 자동으로 HTTPS가 됩니다.

**⑤ 맥 미니를 상시 서버로 쓰기** (선택)

맥 미니를 켜두고 여행 내내 돌릴 거라면, 로그인할 때 자동 실행되게 할 수 있습니다.
`mac/com.icca.baekdu.plist` 파일을 열어 `__경로__` 세 곳을 실제 폴더 경로로 바꾼 뒤:

```bash
cp mac/com.icca.baekdu.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/com.icca.baekdu.plist   # 시작
launchctl unload ~/Library/LaunchAgents/com.icca.baekdu.plist # 중지
tail -f data/server.log                                       # 로그 보기
```

서버가 죽어도 자동으로 다시 뜨고(`KeepAlive`), `caffeinate`로 잠자기도 막습니다.
`node` 경로가 `/usr/local/bin/node`가 아니면(Apple Silicon + Homebrew는 보통
`/opt/homebrew/bin/node`) plist 안의 경로를 `which node` 결과로 바꿔주세요.

**⑥ 참가자에게 안내할 것**

주소를 단톡방에 올리고, 접속 후 **"홈 화면에 추가"** 를 눌러 앱처럼 쓰라고 알려주세요.
(iOS: 공유 → 홈 화면에 추가 / Android: 메뉴 → 홈 화면에 추가)

> HTML·CSS·JS는 `no-cache`로 내려가 보통은 바로 반영되지만, 예전에 캐시된 파일이 남아 있을 수 있습니다.
> 사진(`/img`)은 파일이 바뀌지 않으므로 7일간 캐시합니다.

## 8. 데이터 관리

| 항목 | 위치 |
|---|---|
| 데이터베이스 | `data/baekdu.db` (SQLite) |
| 원본 사진·영상 | `data/uploads/` |
| 썸네일 | `data/thumbs/` |

**백업** — 서버를 끄고 `data` 폴더를 통째로 복사하면 끝입니다.
SQLite 파일이라 Windows ↔ macOS 사이에서도 그대로 옮겨집니다.

> **다른 컴퓨터로 옮길 때** — `data` 폴더는 그대로 복사하고,
> **`node_modules` 폴더는 복사하지 마세요.** OS마다 다시 설치해야 합니다.
> (아직 올린 사진이 없다면 `data`도 복사할 필요 없이 새로 만들어집니다.)

```bash
npm run seed        # 명단·방문지 갱신 (비밀번호를 바꾼 사람은 그대로 둠)
npm run reset-db    # 모든 비밀번호를 휴대폰 번호로 되돌림 (사진은 안 지움)
npm run smoke       # 서버 기능 점검 (별도 테스트 DB 사용)
```

사진까지 전부 지우려면 서버를 끄고 `data` 폴더를 삭제한 뒤 다시 시작하세요.

## 11. 보안 · 개인정보

이 저장소는 **비공개(private)** 입니다. 참가자 75명의 이름과 휴대폰 번호가
`server/data/participants.js` 에 들어 있고, **그 번호가 곧 초기 비밀번호**이기 때문입니다.

> ⚠️ **저장소를 공개로 바꾸지 마세요.** 공개하면 75명의 연락처와 로그인 비밀번호가
> 그대로 노출됩니다. 공개가 필요하다면 명단을 별도 파일로 분리한 뒤에 하세요.

**저장소에 올리지 않는 것** (`.gitignore` 처리됨)

| 대상 | 이유 |
|---|---|
| `참고자료/` | `룸메이트 배정표.png` 에 **75명의 여권번호·여권만료일**이 들어 있습니다 |
| `data/` | 참가자들이 올린 실제 사진·영상과 DB |
| `.env` | 세션 키, 관리자 비밀번호 |
| `node_modules/` | OS마다 다시 설치해야 합니다 |

**앱 자체가 지키는 것**

- 여권번호는 **DB에 저장하지 않습니다.** 명단에서 성명·기수·연락처만 가져옵니다.
- 비밀번호는 bcrypt 해시로만 보관합니다.
- 연락처는 운영진 화면에서만 보입니다. 일반 참가자 API에는 포함되지 않습니다.
- 사진·영상 원본은 로그인한 사람만 볼 수 있습니다.
- 로그인 시도 제한(10회 실패 시 5분 잠금)이 걸려 있습니다.
