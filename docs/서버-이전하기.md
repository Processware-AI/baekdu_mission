# 서버 이전하기 — 맥 미니 → 인텔 iMac

앱 자체는 아키텍처를 가리지 않습니다. 다만 **컴파일된 모듈**과 **Homebrew 경로**가 다르고,
**터널은 두 대에서 동시에 돌리면 안 됩니다.**
아래 순서를 그대로 따르면 주소(`icca-mc.processware.co.kr`)는 그대로 유지됩니다.

- 서비스 중단: 약 5분 (5~9단계)
- DNS 변경: 없음
- 옮길 데이터: `data/` 폴더

---

## 1단계 — iMac 준비 (맥 미니는 계속 켜둔 채로)

### 01. Node 20 이상과 cloudflared 설치

인텔 맥은 Homebrew가 `/usr/local` 에 깔립니다. 뒤에서 쓸 경로이니 결과를 적어두세요.

```bash
brew install node cloudflared

node -v            # v20 이상이어야 합니다
which node         # → /usr/local/bin/node
which cloudflared  # → /usr/local/bin/cloudflared
```

### 02. 저장소 내려받기

맥 미니에서 폴더를 통째로 복사하지 마세요. `node_modules` 안의 `better-sqlite3` 가
arm64로 컴파일돼 있어 인텔에서 동작하지 않습니다.

```bash
mkdir -p ~/MyProjects && cd ~/MyProjects
git clone git@github.com:Processware-AI/baekdu_mission.git
cd baekdu_mission
npm install        # 이 맥에 맞게 새로 컴파일됩니다
```

SSH 키가 없으면 HTTPS로 받아도 됩니다.
`git clone https://github.com/Processware-AI/baekdu_mission.git`

### 03. 터널 자격증명 복사

이 두 파일이면 같은 터널을 그대로 이어받습니다.
다른 터널(danseong, processware) 설정은 가져가지 마세요 —
`~/.cloudflared/config.yml` 을 함께 옮기면 `cloudflared` 명령이 그 파일을 자동으로 읽어
엉뚱한 터널로 동작합니다.

```
~/.cloudflared/icca-mc.yml
~/.cloudflared/664c263b-edff-4e9d-a8d2-dbfe650156ec.json
```

> **계정 이름이 다르면** `icca-mc.yml` 안의 `credentials-file` 경로를 새 경로로 고쳐야 합니다.
> 지금은 `/Users/dongseok/…` 로 박혀 있습니다.

### 04. 자동 실행 파일 두 개 고치기 (등록은 아직)

저장소 `mac/` 안의 두 plist를 인텔 경로로 바꿉니다.

| 파일 | 고칠 곳 |
|---|---|
| `com.icca.baekdu.plist` | `__경로__` · `__사용자__` · `__NODE__` |
| `com.cloudflare.cloudflared-icca-mc.plist` | cloudflared 경로, `icca-mc.yml` 경로 |

## 2단계 — 전환 (여기서부터 순서가 중요합니다)

### 05. [맥 미니] 앱과 터널 내리기

여기서부터 서비스가 멈춥니다. 참가자가 쓰지 않는 시간에 하세요.

```bash
sudo launchctl unload /Library/LaunchDaemons/com.cloudflare.cloudflared-icca-mc.plist
sudo launchctl unload /Library/LaunchDaemons/com.icca.baekdu.plist
```

### 06. [맥 미니] 데이터 복사

앱을 내린 뒤에 복사해야 DB가 쓰는 도중에 잘리지 않습니다.
사진·영상·점수가 모두 이 폴더 안에 있습니다.

```bash
cd ~/MyProjects/baekdu_mission
rsync -av data/ 사용자@iMac주소:~/MyProjects/baekdu_mission/data/
```

여행 전이라 테스트 자료뿐이라면 건너뛰고, iMac에서 운영진 → 🧹 초기화로 시작해도 됩니다.

### 07. [iMac] 앱만 먼저 띄워서 확인

터널을 올리기 전에 앱이 제대로 도는지부터 봅니다. 문제가 있으면 여기서 잡는 편이 쉽습니다.

```bash
cd ~/MyProjects/baekdu_mission
node server/index.js

# 다른 터미널 창에서
curl -o /dev/null -s -w "%{http_code}\n" http://localhost:8080/   # → 200
```

참가자 명단과 사진이 보이는지 브라우저로도 확인한 뒤 `Ctrl+C` 로 끕니다.

### 08. [iMac] 데몬 두 개 등록

```bash
sudo cp mac/com.icca.baekdu.plist /Library/LaunchDaemons/
sudo cp mac/com.cloudflare.cloudflared-icca-mc.plist /Library/LaunchDaemons/
sudo launchctl load /Library/LaunchDaemons/com.icca.baekdu.plist
sudo launchctl load /Library/LaunchDaemons/com.cloudflare.cloudflared-icca-mc.plist
```

### 09. [iMac] 고정 주소로 최종 확인

```bash
curl -o /dev/null -s -w "%{http_code}\n" https://icca-mc.processware.co.kr/

# 200 이 아니면 로그부터
tail -f data/server.log
tail -f /Library/Logs/com.cloudflare.cloudflared-icca-mc.err.log
```

휴대폰으로도 접속해 사진 한 장을 올려보세요. 여기까지 되면 이전이 끝난 것입니다.

### 10. [맥 미니] 자동 실행 해제

파일을 남겨두면 맥 미니를 재부팅할 때 다시 올라와 터널이 두 대에서 겹칩니다.
`unload` 만으로는 부족하고 파일까지 지워야 합니다.

```bash
sudo rm /Library/LaunchDaemons/com.icca.baekdu.plist
sudo rm /Library/LaunchDaemons/com.cloudflare.cloudflared-icca-mc.plist
```

## 빠지기 쉬운 함정

**`node_modules` 를 복사해 오면 앱이 안 뜹니다.**
`better-sqlite3` 는 컴파일된 모듈이라 arm64 바이너리가 인텔에서 실행되지 않습니다.
`시작하기.command` 로 실행하면 스스로 감지해 다시 설치하지만,
데몬으로 띄울 때는 그 검사를 거치지 않습니다.

**plist 안의 절대경로 — 가장 흔한 실패.**
launchd 는 PATH 를 거의 물려받지 않아 실행 파일을 전체 경로로 적어야 합니다.
인텔에서 `/opt/homebrew/bin/node` 를 그대로 두면 아무 메시지 없이 안 뜹니다.

| | 애플 실리콘 | 인텔 |
|---|---|---|
| node | `/opt/homebrew/bin/node` | `/usr/local/bin/node` |
| cloudflared | `/opt/homebrew/bin/cloudflared` | `/usr/local/bin/cloudflared` |

**터널을 두 대에서 동시에 돌리지 마세요.**
같은 터널 ID로 두 대가 붙으면 Cloudflare 가 요청을 양쪽에 나눠 보냅니다.
사진이 어느 쪽에 저장됐는지 뒤섞이고 원인 찾기도 어렵습니다.
반드시 05번(내리기)을 먼저 하고 08번(올리기)을 하세요.

**DNS 는 건드릴 필요가 없습니다.**
`icca-mc.processware.co.kr` 은 터널 ID 를 가리키고 있어서,
그 터널을 어느 기계에서 띄우든 주소는 그대로입니다.

## 옮긴 뒤에

**운영진 비밀번호 바꾸기** — 기본값은 공개 저장소에 그대로 적혀 있습니다.
주소가 인터넷에 상시 공개되어 있으니 참가자에게 알리기 전에 바꾸세요.

```bash
cp .env.example .env
# ADMIN_PASSWORD 와 SESSION_SECRET 을 고친 뒤
sudo launchctl kickstart -k system/com.icca.baekdu
```

**전원 설정** — 시스템 설정 → 잠자기에서 디스플레이만 끄고 컴퓨터는 잠들지 않게 두세요.
앱이 `caffeinate` 로 잠자기를 막고 있지만, 유선 랜이면 더 안정적입니다.
